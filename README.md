# Biomedical Informatics — Learning Path & Playbook

Two companion tools for studying biomedical informatics and biological sciences.

## Contents
- **`learning-path.html`** — 12 visual micro-lessons across 3 stages, with an offline AI tutor in every card
- **`playbook.html`** — practical playbook with workflows and reference material
- **`index.html`** — landing page linking both

## Live site
https://narissa-pgm.github.io/biomed-learning-path/

## Run locally
Open `index.html` in any modern browser. No build step, no dependencies.
